One funny line for the door of a haunted server room, at most 120 characters. The sign is taped up by the ghost itself: it has moved into rack 4, and a reboot would be an eviction. The program writes the line to `/output/entry.txt`.

> DO NOT REBOOT RACK 4. I LIVE THERE NOW. — THE GHOST

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The program validates the line (1–120 characters, a single line, not only white space) and writes it to `/output/entry.txt`.
